    #比赛配置

    比赛（Contest）是 CBCTF 的核心组织单元，每场比赛包含独立的题目集、队伍、排行榜和作弊检测记录。

    #比赛状态

    状态时间说明
    未开始开始时间之前参赛者可加入队伍，尚不能查看题目
    进行中开始时间至结束时间可进入公开比赛查看题目和提交 Flag
    已结束结束时间之后不再接受 Flag 提交

    #基本设置

    设置说明
    名称与介绍比赛展示内容，介绍支持 Markdown
    Flag 前缀选手提交的 Flag 前缀，例如 flag、CTF、CBCTF
    队伍人数每队最多可加入的人数
    开始与结束时间控制题目开放和 Flag 提交时段
    三血奖励为前三支解出 Flag 的队伍提供额外分数
    隐藏比赛隐藏后普通选手无法访问，准备完成后再公开
    比赛验证码创建队伍时需填写，留空则不校验
    靶机上限每队同时运行的靶机数量，至少为 1
    规则、奖励、时间线在比赛详情展示的参赛说明

    #Flag 前缀

    Flag 前缀决定比赛中生成的 Flag 格式：

    static{content}  →  {prefix}{content}
leet{content}    →  {prefix}{随机内容}
uuid{}           →  {prefix}{uuid}

    例如，prefix: "flag" 则选手提交 flag{...}；prefix: "CBCTF" 则提交 CBCTF{...}。

    创建比赛时默认前缀为 CBCTF。清空前缀后，生成结果不包含前缀及外层花括号。请在发布题目前确认前缀；修改后，队伍已经生成的 Flag 仍保持原值。

    #公告系统

    管理员可发布公告，参赛者可在比赛公告页面实时查看。

    #奖励配置

    在比赛编辑页逐项添加奖项和说明，例如「一等奖 — ¥5000」「二等奖 — ¥3000」。奖项用于展示，发放事宜由主办方安排。

    #时间线

    为各个日程填写时间、标题和说明，例如比赛开始、解题截止或颁奖。展示时间线不会自动更改比赛时间，也不会限制题解上传；如需调整比赛结束时间，请修改基本设置。

    #排行榜

    比赛提供三种视图：

    • 总分排名：实时总分排序，支持队伍搜索
    • 时间线视图：各队分数随时间变化的折线图
    • 计分板（Scoreboard）：按队伍行与题目列展示完成情况，并可切换图表查看趋势

    #Writeup 管理

    比赛开始后，已验证且已加入队伍的选手可上传 Writeup（PDF、DOC 或 DOCX），大小受 gin.upload.writeup 限制。管理员可按队下载，或导出整场题解 ZIP。比赛时间线中的题解截止提示不是上传截止配置。

    #题目管理

    从全局题库添加题目后，可为本场比赛单独调整：

    设置说明
    名称与描述比赛中显示的题目内容
    标签与提示题目标签和解题提示
    隐藏题目准备完成后取消隐藏
    提交次数每队尝试次数限制，0 表示无限制

    分类沿用添加时的题库分类。每个 Flag 的计分方式、初始分值、最低分值和衰减参数也可单独配置。新增比赛题目默认隐藏，准备完成后再发布。
