# 选手操作流程

## 注册与登录

在 `/platform/#/login` 使用用户名、密码和图形验证码登录。开放注册时可以切换注册表单；已启用的 OAuth/CAS 提供商显示在登录页。

本地注册后检查邮箱验证邮件，也可以在个人设置重新发送。页面能登录但题目或队伍接口提示权限不足时，请让管理员检查注册默认分组；邮箱未验证时先完成验证。

## 创建或加入队伍

从比赛列表打开比赛详情：

- 创建队伍：填写队伍名称、简介；比赛设置了报名验证码时需填写比赛验证码。
- 加入队伍：使用队伍名称和该队的邀请码。它与比赛验证码、登录图形验证码是三种不同的信息。
- 每位用户在同一场比赛只能加入一支队伍，人数不得超过比赛上限。
- 比赛未结束前可创建/加入队伍；后端只允许比赛开始前退队、踢人或解散队伍。当前队伍页提供队长踢人和解散操作，普通成员退队没有独立按钮，可联系管理员处理。

队伍页提供成员、队伍信息和邀请码；队长可以编辑信息、重置邀请码及转移队长。

## 题目与 Flag

比赛开始后，已加入队伍且未被封禁的用户可以进入题目页，按分类筛选、查看提示、初始化题目或提交 Flag。

| 题型    | 操作                               |
| ----- | -------------------------------- |
| 静态题   | 下载共享附件，在有初始化提示时先初始化，再提交答案        |
| 动态附件题 | 初始化后等待生成任务完成，再下载该队专属附件           |
| 容器题   | 初始化后启动实例，等待 Running，再复制页面提供的访问地址 |

同队共享团队 Flag 和实例。多 Flag 题目需要逐个提交，已解部分与全部完成是不同状态；注意提交次数上限与比赛前缀。

「重置」不是刷新页面：它重新生成团队 Flag、清理该题提交记录，并触发附件重建或停止旧靶机。只在比赛进行中且满足题目未完成等条件时可用。

## 靶机控制

启动经过 waiting、pending、running 状态；停止进入 terminating，异步回收后结束。操作成功提示首先表示任务已提交，不能立即视为服务可访问。

页面提供启动、停止和延长操作，以及剩余时间。延长只在比赛进行中可用；每队实例数量受比赛的 `victims` 限制。VM 服务不会自动显示端口，需要按题目说明的入口访问。

比赛结束后不能继续初始化、重置或提交 Flag；现有附件仍可按权限下载。容器启动接口当前允许已初始化题目在赛后启动，是否可用还取决于实例限额及管理员资源清理。

## 排行榜、公告与题解

比赛导航可进入排行榜、公告和题解页面。分数受动态计分及周期刷新影响，提交成功后其他队伍总分可能稍后更新。

题解允许 `.pdf`、`.doc`、`.docx`，上传大小由平台控制。比赛开始后即可上传，上传记录归队伍保存。管理员可以下载单队题解或导出整场 ZIP；请按赛事规则确认截止时间，页面时间线不会自动限制提交。
